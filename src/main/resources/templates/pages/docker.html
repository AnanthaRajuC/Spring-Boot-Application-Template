The Image

The Dockerfile is a multi-stage build: eclipse-temurin:21-jdk packages the jar with the Maven wrapper, eclipse-temurin:21-jre runs it as a non-root user on port 8080. No local Java or Maven is needed to build it.

docker build -t spring-boot-application-template .

Docker Compose

docker-compose.yml starts MySQL 8.4 and the application in the production profile. Create the JWT key store at secrets/jwt.p12 first (see the Security page), then:

export DB_PASSWORD=... DB_ROOT_PASSWORD=... JWT_KEY_STORE_PASSWORD=... REMEMBER_ME_KEY=$(openssl rand -base64 32)
docker compose up --build
CommandDescription
docker compose configValidate the file and show the resolved configuration
docker compose up --buildBuild the application image and start the containers
docker compose logs -f appFollow the application logs
docker compose downStop and remove the containers (the database volume is kept)
docker compose down -vAlso remove the database volume

Without a Database

docker run --rm -p 8080:8080 -e SPRING_PROFILES_ACTIVE=test spring-boot-application-template
