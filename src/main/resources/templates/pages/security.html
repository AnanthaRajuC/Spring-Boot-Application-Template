JWT Signing Key

Access tokens are signed with an RSA key pair. Without a configured key store a temporary key pair is generated at startup (fine for development; tokens stop working on restart). In production create a key store, keep it out of the repository, and set JWT_KEY_STORE, JWT_KEY_STORE_PASSWORD and JWT_KEY_ALIAS:

keytool -genkeypair -alias sbat -keyalg RSA -keysize 2048 -validity 3650 \
        -storetype PKCS12 -keystore secrets/jwt.p12 -dname "CN=sbat"

Login Throttling

Failed logins are counted per client IP address (form login, HTTP Basic and the API login). After 5 failures the address is blocked for 15 minutes, configurable with sbat.security.max-login-attempts and sbat.security.login-block-duration. Behind a reverse proxy set FORWARD_HEADERS_STRATEGY, otherwise X-Forwarded-For is ignored.

Actuator

/actuator/health and /actuator/info are public; every other endpoint, including /actuator/prometheus, requires ROLE_ADMIN.
