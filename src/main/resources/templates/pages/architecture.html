Overview

A monolithic Spring Boot application that serves a server-rendered web UI (Thymeleaf) and a REST API from the same process and database.

  • core_backend: reusable building blocks (security, persistence base classes, API utilities, e-mail, configuration). Keep it when you start your own project.
  • example: a sample domain (persons with addresses) showing controllers, services, repositories, DTOs, HATEOAS, caching and role based access.
  • web: controllers of the web UI pages.

EER Diagram

The authentication and authorization is governed by the User, Role and Permission tables.

Resources

  • application.properties: shared configuration; application-<profile>.properties overrides it for test (H2), dev, qa, staging and production.
  • data/h2db/migrations, data/mysql/migrations: Flyway scripts for the table structure and seed data.
  • i18n: translated texts.
  • static: css, js and images.
  • templates: layout.html, fragments (head, navigation, footer, scripts) and pages.
